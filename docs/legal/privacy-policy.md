## 2. 처리하는 개인정보 항목

본 앱은 **익명 사용 통계(Telemetry)** 외의 개인정보를 수집하지 않으며,
모든 텔레메트리는 **사용자의 명시적 동의(Opt-in)** 후에만 수집됩니다.

### 2.1 익명 사용 통계 (선택 동의)

| 항목 | 내용 | 식별성 |
|---|---|---|
| `anonId` | 설치 시 생성된 임의 UUID v4 (앱 재설치 시 재생성) | 익명 |
| `event` | 사용자 행동 이벤트명 (예: `tg.stage.entered`) | 익명 |
| `timestamp` | 이벤트 발생 시각 (UTC ISO 8601) | 익명 |
| `appVersion` | 앱 버전 문자열 | 익명 |
| `props` | 이벤트별 화이트리스트 속성 (`docs/legal/data-categories.md` 참조) | 익명 |

수집되지 **않는** 정보:

- 이름·이메일·전화번호 등 직접 식별자
- IP 주소 (백엔드 액세스 로그에는 단기간 남을 수 있음 — 4항 참조)
- 사용자가 입력한 명령어 원문, 파일 내용, 코드
- 디바이스 시리얼·MAC 주소·하드웨어 ID

### 2.2 베타 메일링 (선택)

랜딩 페이지에서 사용자가 직접 이메일을 보낸 경우에만 수집:
- 이메일 주소 (베타 안내 회신 목적)

## 3. 처리 목적 및 법적 근거

| 처리 목적 | 처리 항목 | 법적 근거 (GDPR Art.6) | 동의 형태 (PIPA) |
|---|---|---|---|
| 제품 개선·버그 분석 | 익명 사용 통계 | (a) Consent | 선택 동의 |
| 베타 안내 | 이메일 주소 | (a) Consent | 선택 동의 |
| 자동 업데이트 제공 | 액세스 로그 (IP, User-Agent, 버전) | (b) Contract / (f) Legitimate Interest | 필수 (서비스 제공) |
| 보안 사고 대응 | 액세스 로그 | (c) Legal Obligation / (f) Legitimate Interest | 필수 |

**필수 동의 항목 없음** — 텔레메트리·메일링은 모두 선택입니다. 거부해도 앱의 모든 기능은 정상 동작합니다.

## 7. 정보주체의 권리

GDPR Art.15-22, PIPA 제35-39조, CCPA §1798.100-130 에 따라 다음 권리를 행사할 수 있습니다:

| 권리 | 행사 방법 |
|---|---|
| 열람권 (Access) | <TBD: privacy@example.com> 으로 `anonId` 첨부하여 요청 |
| 정정권 (Rectification) | 동상 |
| 삭제권 (Erasure / "Right to be forgotten") | 앱 내 `설정 → 데이터 삭제 요청` 또는 이메일 |
| 처리 제한권 (Restriction) | 동상 |
| 데이터 이동권 (Portability) | 동상 |
| 자동화된 결정에 대한 권리 | 본 앱은 자동화된 의사결정 미사용 |
| 동의 철회권 | 앱 내 `설정 → 익명 사용 통계` 토글로 즉시 철회 |
| CCPA Opt-out | 본 앱은 개인정보를 판매하지 않으므로 자동 충족 |

요청 처리 기한: GDPR 30일 이내, PIPA 10일 이내, CCPA 45일 이내.

## 10. 쿠키 및 유사 기술

본 앱은 데스크톱 애플리케이션으로 쿠키를 사용하지 않습니다.
대신 동일 기능의 식별자로 `anonId`(localStorage 에 저장된 임의 UUID)를 사용합니다.
랜딩 페이지(웹)는 분석 쿠키를 사용하지 않습니다 (필요 시 사전 동의 배너 적용 예정).
