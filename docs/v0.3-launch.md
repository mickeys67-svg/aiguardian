## 2. 사용자 플로우 (9단계, end-to-end 시뮬레이션 통과)

```
vibemate.kr(코치 랜딩)
  → [다운로드] 익명이면 로그인 게이트
  → [Google 로 시작] 구글 동의 → 세션
  → 로그인 후 코치 v0.3.0 다운로드 (OS 자동감지)
  → 설치·실행 → 코치 대시보드(앱 현관)
  → [코치 켜기] → ~/.claude/settings.json 에 Stop 훅
  → Claude Code 한 턴 종료 → 훅 발화 → 코칭(systemMessage, 사람에게만)
  → 앱 HUD "방금 한 턴" 🟢 라이브
  → 새 버전 나오면 자동업데이트(서명 검증)
```

데스크탑 Claude 는 훅 대신 `.mcpb` 확장(coach_review) — "코치 봐줘" 한마디로 호출.

## 3. 아키텍처 (단일 코어 + 클라별 어댑터)

```
packages/coach/
  core/      클라 독립 5버킷 조언 엔진(존댓말·OS인자)
  shared/    transcript 파서 + HUD 상태파일(~/.tg-coach/latest-turn.json)
  adapters/  claude-code(systemMessage) · cursor(user_message) · mcp(coach_review)
apps/desktop/        Tauri 코치 앱 — CoachDashboard(HUD·코치 켜기) + 섹션 + 설정
services/backend/    Cloudflare Worker — Google OAuth + 로그인-게이트 /download + /updates
apps/landing/        Cloudflare Pages — 코치 랜딩 + 로그인 플로우
```

스탠스(불변식, stance-lint 강제): 앱이 명령을 **대신 실행 안 함**, 명령은 "복사"만, 조언은
**사람에게만**(AI 안 떠밂). 현재 stance-lint = **0**.
