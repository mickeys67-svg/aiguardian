Executive Summary
Terminal Guardian은 "AI로 앱을 만들 수 있다는 말은 들었지만 어디서부터 시작해야 할지 모르는 입문자"가, 컴퓨터를 켠 첫 순간부터 자기 작품을 인터넷에 배포하는 마지막 순간까지 끊김 없이 안내받을 수 있도록 설계된 데스크톱 가디언이다.
Cursor·Replit·Claude Code 같은 기존 바이브코딩 도구는 "이미 개발 환경이 갖춰진 사용자"를 전제로 한다. 그러나 진짜 입문자는 터미널이 무엇인지, Python을 어디에 까는지, MCP가 뭔지조차 모른다. 이 0→1 구간이 시장의 빈 공간이며, Terminal Guardian이 책임지는 영역이다.

1. 프로젝트 개요
1.1 비전 진술
비전
바이브코딩의 진입장벽을 0으로 만든다. 컴퓨터를 처음 켠 사람이 30분 안에 자신의 첫 앱을 인터넷에 띄우고, 6개월 뒤에는 가디언 없이도 만들 수 있는 사람이 되도록 끌어올린다.
1.2 해결하려는 문제
AI 코딩 도구의 발전으로 "프롬프트로 앱을 만든다"는 약속은 현실이 되었지만, 그 약속을 누리는 사람은 *이미 개발자인 사람*에 한정된다. 진짜 입문자는 다음 7가지 단계 모두에서 막힌다:
터미널이 무엇인지 모르고, 어떻게 여는지도 모름
Python·Node 같은 런타임을 어디서 다운로드하는지 모름
Claude Desktop을 깔았지만 MCP 연결 방법을 모름
AI한테 코드를 받았지만 어디에 저장하고 어떻게 실행할지 모름
에러 메시지를 영어로 마주치면 어디서부터 봐야 할지 모름
내 컴퓨터에서는 돌아가는데 다른 사람에게 보여주는 방법(배포)을 모름
"다음에 뭘 배워야 하지?"의 학습 이정표를 모름
Terminal Guardian은 이 7개 모두를 한 도구 안에서 책임진다.

2. 바이브코딩 플로우 대규모 분석
2.1 분석 방법론
실제 입문자가 AI로 첫 앱을 만들기까지 거치는 여정을 10단계로 분해했다. 각 단계는 다음 5개 항목으로 분석된다:
사용자 상태 — 그 시점에 사용자가 처해 있는 인지·정서 상태
주요 행동 — 사용자가 수행해야 하는 핵심 작업
차단 요인 — 입문자가 그 단계에서 실제로 막히는 지점
가디언 개입 — Terminal Guardian이 이 단계에서 자동으로 또는 가이드로 수행하는 것
팁 인젝션 포인트 — 단계 안에서 짧은 학습·격려·맥락 메시지를 끼워 넣는 구체 시점
"팁 인젝션"은 본 가디언의 핵심 차별 기능이다. 입문자는 한 번에 모든 것을 배울 수 없다. 따라서 *지금 이 순간 필요한 한 줄 정보*를 적절한 시점에 던지는 것이 핵심이다.
2.2 10단계 입문자 여정
Stage 0. 인지·동기 형성
사용자 상태: AI로 앱을 만들 수 있다는 것을 어디서 들었지만 실감하지 못함. "내가 정말 할 수 있을까?"라는 자기효능감 부족.
주요 행동: 가디언 다운로드 페이지 방문 → 다운로드 결정
차단 요인: 
"또 어려운 거 아냐?" 학습 부담 우려
"비용 들어가는 거 아냐?" 경제적 부담
"내가 진짜 가능?" 자기효능감 결여
주변에 도와줄 사람 없음
가디언 개입: 랜딩페이지 5분 데모 영상, 무료 명시, 실제 입문자 후기, 친근한 톤
팁 인젝션 포인트:
랜딩페이지 진입 시 (3초): "걱정 마세요. 컴맹도 30분이면 첫 앱 띄워요"
다운로드 직전 (5초): "지금 다운로드한 사람 평균 수준은 &#x2018;엑셀 사용 가능&#x2019; 정도예요"
다운로드 후 (10초): "설치는 1분 안에 끝나요. 비밀번호 한 번만 물어볼 거예요"
Stage 1. 환경 부트스트랩 (첫 진단)
사용자 상태: 가디언 첫 실행. 자기 컴퓨터에 뭐가 있는지 본 적이 없음. 약간의 긴장감.
주요 행동: 환영 화면 → 자동 환경 진단 시작 → 결과 카드 확인
차단 요인: 
"내 정보 보는 거 아냐?" 개인정보 우려
진단 결과 영어 용어 폭격에 위축
"부족한 게 너무 많아 보임" 좌절
가디언 개입: 스캔 의미·범위 시각화, 모든 항목에 1줄 한국어 설명, 결과를 "필요한 것만 보여주기"
팁 인젝션 포인트:
진단 시작 전 (5초): "당신 컴퓨터에 뭐가 깔렸는지만 봐요. 파일 내용은 절대 안 봐요"
진단 진행 중 (총 30초, 단계마다 1줄): "터미널 확인 중...", "Python 확인 중...", "Git 확인 중..."
결과 표시 후 (10초): "걱정 마세요. 부족한 건 제가 다 깔아드릴게요"
항목 호버 (1줄): 각 도구 옆 ⓘ 클릭 시 "이건 ~ 의미예요"
Stage 2. 목표 설정
사용자 상태: "근데 뭘 만들어보지?" 막연함. 너무 큰 꿈과 작은 자신감 사이의 간극.
주요 행동: 카테고리 갤러리에서 첫 프로젝트 선택
차단 요인: 
선택지 너무 많음 (분석 마비)
자기 수준에 맞는 게 뭔지 모름
"이거 만들면 뭐가 좋지?" 동기 약함
가디언 개입: ⭐ "처음이면 이거" 추천 표시, 난이도·예상 시간 명시, "만들면 무엇이 가능한지" 결과 미리보기
팁 인젝션 포인트:
갤러리 진입 시 (5초): "처음이면 ⭐ 표시된 거 추천해요. 5분이면 끝나요"
카드 호버 (3초): "예상 30분 · 필요 도구 2개 · 끝나면 친구한테 링크 보낼 수 있어요"
카드 선택 후 (5초): "잘 골랐어요! 이거 만들면 &#x2018;진짜 코딩 좀 하네?&#x2019; 소리 들어요"
망설임 감지 (10초 이상 머무름): "고민되시면 그냥 ⭐ 가요. 나중에 다른 거 해도 돼요"
Stage 3. 도구 설치
사용자 상태: "부족한 거 깔아야 한다는데..." 약간의 불안. 권한 다이얼로그가 무서움.
주요 행동: Homebrew/winget 통한 자동 설치 동의 → 시스템 비밀번호 입력 → 다운로드 대기
차단 요인: 
관리자 비밀번호 요구가 무서움
다운로드 대기 시간 동안 불안 (멍하니 봄)
진행 중 멈춤·실패 발생 시 어쩔 줄 모름
가디언 개입: 비밀번호 사전 설명, 다운로드 중 학습 카드 자동 노출, 실패 시 자동 재시도 + 대안 경로
팁 인젝션 포인트:
설치 시작 전 (10초): "비밀번호 한 번 물어볼 거예요. &#x2018;이 프로그램이 컴퓨터에 다른 프로그램을 깔아도 돼?&#x2019; 확인이에요. 안전해요"
다운로드 중 (15초마다 1개): "Python이 뭔지 알아볼래요? 컴퓨터한테 시킬 수 있는 언어 중 하나예요. 영어처럼."
다운로드 중 (30초마다 1개): "지금 깔리는 Git은 코드의 &#x2018;저장 기록&#x2019; 도구예요"
설치 완료 후 (5초): "성공! 이걸 어떻게 확인하는지 보여드릴까요?" (선택)
실패 시 (즉시): "잠깐 막혔어요. 다른 방법으로 해볼게요" (자동 재시도)
Stage 4. AI 연결 (MCP 등록)
사용자 상태: Claude Desktop 등을 깔았지만 MCP가 무엇인지 모름. "왜 이게 필요해?"
주요 행동: AI 클라이언트 자동 감지 → MCP 설정 파일 자동 수정 → 연결 검증
차단 요인: 
"MCP" 용어 자체 모름
JSON 설정 파일 만지는 게 무서움
연결 성공 여부 확인 방법 모름
가디언 개입: 설정 파일 자동 처리, 시각적 연결 상태 (✅/❌), Claude한테 "보이지?" 물어볼 수 있는 검증 메시지
팁 인젝션 포인트:
연결 시작 전 (10초): "MCP는 AI랑 당신 컴퓨터를 연결하는 &#x2018;다리&#x2019;예요. 저(가디언)가 그 다리를 자동으로 놓을게요"
연결 중 (5초): "Claude Desktop 설정 파일 찾는 중... 자동으로 수정할게요"
연결 후 (15초): "이제 Claude한테 &#x2018;내 가디언 보여?&#x2019;라고 물어보세요. 보인다고 하면 성공!"
검증 실패 시 (즉시): "연결이 약해요. 다시 시도할게요" (자동 재시도)
Stage 5. 첫 코드 받기 (프롬프트)
사용자 상태: "AI한테 뭐라고 시키지?" 프롬프트 공포. 자기 표현이 부족하다고 느낌.
주요 행동: 레시피의 프롬프트 템플릿 복사 → AI한테 전달 → 코드 응답 받기
차단 요인: 
프롬프트 작성 막막
AI 응답 길이에 압도
코드가 코드인지 설명인지 헷갈림
가디언 개입: 레시피별 프롬프트 템플릿 제공, AI 응답 자동 파싱하여 "이건 코드, 이건 설명" 표시
팁 인젝션 포인트:
프롬프트 보내기 전 (10초): "이 템플릿 그대로 보내도 돼요. 익숙해지면 자기 말로 바꿔도 돼요"
응답 대기 중 (5~30초): "AI가 지금 &#x2018;어떻게 만들지&#x2019; 고민 중이에요. 저처럼요"
코드 도착 시 (10초): "이게 코드예요. 컴퓨터한테 시킬 명령들이에요. 뜻을 한 줄씩 보여드릴까요?" (선택)
코드 길이 위협적일 때 (5초): "길어 보여도 괜찮아요. 한 줄씩 다 설명해드릴게요"
Stage 6. 실행·결과 확인
사용자 상태: "이걸 어떻게 돌리지?" 터미널 두려움.
주요 행동: 코드를 적절한 폴더에 저장 → 터미널에서 명령 실행 → 결과 확인
차단 요인: 
저장 위치 결정 못 함
명령어 입력 두려움
"성공/실패" 출력 해석 못 함
가디언 개입: 자동 저장 위치 제안 (~/projects/{project_name}), dry-run 미리보기, 결과 자동 해석
팁 인젝션 포인트:
저장 직전 (5초): "이 폴더는 당신만의 작업실이에요. ~/projects/myapp 으로 만들게요"
명령어 보여주기 (10초): "이 명령어는 &#x2018;이 폴더로 이동해서 코드를 실행해&#x2019; 라는 뜻이에요"
실행 직전 (5초, 위험 명령일 때): "이 명령어는 파일을 만들어요. 삭제는 안 해요. 실행할까요?"
실행 성공 후 (10초, 컨페티 애니메이션): "축하해요! 이게 당신이 만든 첫 앱이에요. 브라우저에서 보여드릴게요"
실행 실패 시 (즉시): "오, 도움 요청이에요. 같이 풀어볼까요?" (Stage 7로)
Stage 7. 에러·디버깅
사용자 상태: 빨간 글자 가득. 첫 좌절 모먼트. 포기 위험 가장 높음.
주요 행동: 에러 메시지 읽기 → 원인 파악 → 수정 → 재실행
차단 요인: 
에러 메시지 영어
어디서부터 봐야 할지 모름
AI한테 다시 가서 컨텍스트 어떻게 전달?
연속 실패 시 자기효능감 급락
가디언 개입: 에러 자동 캡처 + AI 라운드트립, 흔한 에러 200개 로컬 DB 즉시 해결, "에러는 실패가 아니다" 메시지
팁 인젝션 포인트:
에러 발생 즉시 (5초): "에러는 실패가 아니에요. 컴퓨터가 도움 요청하는 거예요"
진단 중 (5초): "이 에러 본 적 있어요. 잠시만요" (로컬 DB 매칭)
로컬 DB 매칭 실패 시 (10초): "AI한테 자동으로 물어볼게요. 답 받으면 적용해드릴게요"
해결 후 (10초): "이번 에러는 &#x2018;파일을 못 찾았다&#x2019; 뜻이었어요. 다음에 또 나오면 알아볼 수 있을 거예요"
연속 실패 (3회 이상, 위로): "오늘 좀 빡세네요. 잠깐 쉬고 와도 돼요. 진행 상태는 다 저장돼 있어요"
Stage 8. 완성·배포
사용자 상태: "내 컴퓨터에서는 되는데... 다른 사람한테 어떻게?" 새로운 막막함.
주요 행동: GitHub 자동 등록 → Vercel/Cloudflare 자동 배포 → 공개 URL 받기
차단 요인: 
GitHub 계정 만들기 부담
"왜 GitHub이 필요해?" 모름
도메인·HTTPS·환경변수 같은 단어들에 압도
가디언 개입: 원클릭 GitHub 가입·푸시, 원클릭 배포, 자동 도메인 (예: myapp-xxxx.terminalguardian.app)
팁 인젝션 포인트:
GitHub 가입 직전 (10초): "GitHub은 &#x2018;코드의 구글 드라이브&#x2019;예요. 무료고, 회원가입 한 번이면 돼요"
푸시 중 (5초): "당신 코드가 GitHub에 안전하게 올라가는 중이에요"
배포 시작 (10초): "이제 인터넷에 띄워볼게요. 5분 안에 끝나요"
배포 중 (30초): "지금 Cloudflare가 당신 앱을 전 세계 어디서든 빠르게 보이도록 준비 중이에요"
배포 완료 (15초, 큰 축하): "이 링크 친구한테 보내보세요! 카톡·문자 어디든 됩니다. 진짜 인터넷 앱이에요"
Stage 9. 반복·성장·졸업
사용자 상태: 첫 성공의 기쁨. "또 만들어볼까?" 동기 상승. 다음 도전 갈증.
주요 행동: 두 번째 프로젝트 시작 → 학습 카드 누적 → 졸업 모드 진입
차단 요인: 
"다음에 뭐 만들지?" 막연함
학습 정체감
가디언에 대한 의존성
가디언 개입: 학습 카드 자동 누적, 다음 레시피 추천, 졸업 진행도 (가디언 도움 비율 ↓)
팁 인젝션 포인트:
첫 성공 후 (15초): "오늘 새로운 명령어 5개 배웠어요. 학습 카드에 저장됐어요"
두번째 시작 시 (10초): "이번엔 좀 더 어려운 거 해볼래요? 또는 비슷한 거 한 번 더?"
익숙해진 명령어 (5초): "&#x2018;cd&#x2019; 명령어는 이제 익숙하시죠? 다음부턴 설명 안 보여드릴게요"
졸업 임박 (15초): "당신은 지금 가디언 도움 없이 60% 가능해요. 80% 되면 &#x2018;졸업&#x2019; 배지 드릴게요"
졸업 (30초, 큰 의식): "축하합니다! 이제 가디언 없이도 가능해요. 그래도 옆에 있을게요. 필요할 때만 부르세요"

필요 도구 갯수 (이미 있는 건 ✅, 깔아야 하는 건 ↓)
"무엇을 배우게 되나요?" 3줄 요약
실행·결과 화면

에러 화면

부록 A. 용어집 (입문자용)
용어
입문자 친화 설명
Terminal (터미널)
컴퓨터한테 명령어로 시키는 검은 화면. Mac은 "터미널", Windows는 "PowerShell"이 기본.
Shell (셸)
터미널이 사용자 명령을 컴퓨터에 전달하는 통역 프로그램. bash·zsh·PowerShell 등.
Runtime (런타임)
Python·Node 같은 "코드를 실행하는 엔진". 코드만 있어도 런타임 없으면 못 돔.
Package Manager
프로그램들을 한 줄로 깔게 해주는 도구. Mac은 Homebrew, Win은 winget.
Git
코드 변경 기록과 협업을 위한 도구. 거의 모든 개발에 기본.
MCP
Model Context Protocol. AI(Claude 등)가 사용자 컴퓨터의 도구·파일에 접근하게 해주는 표준.
Repository (저장소)
GitHub 등에 올려놓은 프로젝트 폴더. "코드의 구글 드라이브".
Deploy (배포)
내 컴퓨터에서만 돌던 앱을 인터넷에 올려서 누구나 볼 수 있게 만드는 것.
HTTPS
인터넷 통신을 암호화하는 보안 프로토콜. 자물쇠 표시.
Environment Variable
비밀번호·API 키 같은 민감 정보를 코드에 직접 안 쓰고 따로 보관하는 방법.
