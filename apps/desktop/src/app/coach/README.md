## 스탠스 불변식 (stance-lint 강제)

- **코드 에디터 없음** — 우리는 IDE가 아니다.
- **AI 채팅 입력창 없음** — 그건 AI 클라이언트의 몫.
- **명령은 "복사" 버튼만, "실행" 버튼 없음** — user-runs, app-coaches.

이 셋이 코치 창과 "마법사/자동화 머신"을 가른다. `runRecipeStep`·`installTool`·실행 버튼을 넣으면 `pnpm stance-lint` 가 잡는다.
